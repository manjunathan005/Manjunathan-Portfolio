CropCare AI – AI-Powered Agricultural Platform

A distributed microservices agricultural ecosystem integrating deep learning disease detection, soil advisories, live mandi pricing, and government welfare schemes.

The Problem Statement

Farmers in India face catastrophic crop losses due to undetected or late-diagnosed leaf diseases, lack of customized soil nutrient recommendations, volatile mandi rates, and fragmented awareness of government agricultural subsidies.

The Architectural Solution

Engineered a microservices-based agricultural platform using Spring Boot, Eureka Service Discovery, and an API Gateway with JWT authentication and role-based access control (RBAC). Powered by a responsive React.js frontend and a dedicated Python FastAPI inference microservice.

Key System Features

  • AI Disease Detection: Integrated an EfficientNetB0 deep learning model via TensorFlow & FastAPI, achieving 94.62% test accuracy.
  • Soil Health & Fertilizer Advisory: Dynamic NPK calculation and crop matching engine.
  • Live Mandi Market Rates: Real-time pricing index and crop commodity market trends.
  • Hyperlocal Weather Feeds: Live meteorological updates and localized farming advisories.
  • Government Schemes Portal: Direct integration with central/state welfare initiatives (PMFBY, PM-Kisan).
  • Role-Based Security: Strict JWT access control separating farmers, agri-officers, and admins.

SIH 2025 Deep Dive

CropCare AI – System Architecture & Engineering

Microservices Pipeline Highlights:

  • Spring Cloud Gateway: Serves as the single edge point for token verification, CORS headers, and reverse proxy routing.
  • Netflix Eureka Registry: Microservices register dynamically on startup, enabling service discovery without hardcoded IPs.
  • Security & RBAC: JWT authorization ensures role separation (FARMER vs. AGRICULTURAL_OFFICER vs. ADMIN).
  • Dual-Database Strategy: Oracle for ACID-compliant structured transactions; MongoDB for high-volume unstructured diagnosis telemetry and cached mandi rates.
Tier Technology Role & Responsibilities
Frontend React.js (HTML5 / CSS3) Dynamic single-page application with camera upload, soil advisory, mandi rates, and schemes portal.
Backend Services Java 21, Spring Boot 3 Decoupled microservices handling business logic, user auth, advisory generation, and external API caching.
Discovery & Routing Eureka & Spring Cloud Gateway Automated service registry, dynamic route filters, and JWT authorization enforcement.
AI Worker Python, FastAPI, TensorFlow Sub-50ms inference server hosting the trained EfficientNetB0 classification pipeline.
Relational Database Oracle Database User credentials, role assignments, audit logs, and verified government schemes data.
NoSQL Database MongoDB Plant scan history, telemetry, geospatial mandi rates, and fertilizer advisories.

EfficientNetB0 Convolutional Neural Network

EfficientNetB0 applies compound scaling across depth, width, and resolution to maximize accuracy while remaining lightweight enough for edge inference. In CropCare AI, the model diagnoses foliar diseases (such as blights, rusts, and leaf spots) from farmer smartphone photographs.

Model: EfficientNetB0 Framework: TensorFlow Server: FastAPI Latency: ~45ms

Developed for the prestigious Smart India Hackathon (SIH 2025), CropCare AI unites the fragmented tools of modern agriculture into a single cohesive platform. Farmers gain:

  2. Fair Market Realization: Direct visibility into real-time Mandi market commodity rates across regional hubs.
