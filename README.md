## 🛠️ Technology Stack Used For This Portfolio

In strict adherence to requirements, this portfolio is built with:

- **HTML5:** Semantic landmark architecture, Open Graph metadata, accessible labels, SVG vector assets.
- **CSS3:** Custom properties (CSS variables), CSS Flexbox & CSS Grid, glassmorphism (`backdrop-filter`), keyframe animations, dark obsidian/charcoal theme with emerald & cyan accents, responsive media queries.
- **Vanilla JavaScript:** 
  - Dynamic animated typing effect.
  - Interactive background particle network canvas.
  - Scroll progress indicator ring around the back-to-top button.
  - Smooth scrolling and active navigation link tracking via `IntersectionObserver`.
  - Accessible mobile drawer hamburger menu.
  - Interactive project visualization switcher (UI Preview vs. Microservices System Architecture).
  - CropCare AI system architecture deep dive modal dialog with tabbed views.
  - Category-based skill filter tabs.
  - One-click copy to clipboard for email and phone numbers with animated toasts.
  - Honest frontend-only contact form linking to default mail client.

**No build tools, NPM packages, or frontend frameworks (React, Vue, Tailwind, Bootstrap, Vite, etc.) are required.**

## 🚀 How To Open & Run On Your MacBook

Since this project uses pure HTML5, CSS3, and Vanilla JavaScript, there is **no build step, no npm install, and no local server installation required**.

### Method 1: Double-Click (Instant)
1. Open **Finder** on your MacBook.
2. Navigate to your project folder: `Desktop` > `portfolio`.
3. Double-click **`index.html`** to open it directly in Safari, Google Chrome, or your default browser.

### Method 2: Terminal `open` Command
Open your macOS Terminal and run:
```bash
cd ~/Desktop/portfolio
open index.html
```
Or open specifically in Google Chrome:
```bash
open -a "Google Chrome" index.html
```

### Method 3: Lightweight Local Python Server (Recommended for Testing)
macOS comes with Python built-in. If you prefer to test via `http://localhost`:
```bash
cd ~/Desktop/portfolio
python3 -m http.server 8000
```
Then visit **[http://localhost:8000](http://localhost:8000)** in any web browser.
